# HTML reference and parity
1. Locate authoritative L01-L03 HTML, embedded game datasets and scripts.
2. Extract original object dimensions/origins/coordinates, colors, trajectory formulas, checkpoints, collectibles, Newton K/I/X controls, and event timing.
3. Record HTML source line/function and conversion formulas; do not round silently.
4. Compare expected level JSON fields and actual Unity runtime consumers, separating data parity from behavioral parity.
5. Flag platform behavior changes for owner approval; never directly modify source.
